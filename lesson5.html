LESSON 5

Building Your First Web Project

In this final lesson, you will learn how HTML, CSS and JavaScript work together to create a complete website.

Putting Everything Together

When building a website, each technology has a different responsibility. 

HTML → Structure
CSS → Design
JavaScript → Interactivity

Step 1 — Create the HTML

HTML gives your website its structure. You can create headings, paragraphs, buttons, images and other elements. 

<h1>My Website</h1>

<p>Welcome to my first project!</p>

<button>Click Me</button>

Step 2 — Add CSS

CSS can then be used to make the website attractive by changing colors, fonts, spacing and layouts. 

h1 {
    color: blue;
}

button {
    padding: 10px 20px;
}

Step 3 — Add JavaScript

JavaScript can make the website respond when the user interacts with it. 

function sayHello() {
    alert("Hello!");
}

What You Have Learned

Throughout these lessons, you have learned the basic concepts of web development.

  • How HTML creates webpage structure
  • How CSS styles webpages
  • How JavaScript adds interactivity
  • How HTML, CSS and JavaScript work together
  • How to begin building your own projects

Your Next Step

The best way to improve as a developer is to keep practicing. Start creating small projects and gradually make them more advanced.
