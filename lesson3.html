LESSON 3

CSS — Styling Your Website

CSS is what makes a website look beautiful. It allows you to control colors, fonts, spacing, layouts and many other visual aspects of a webpage.

What is CSS?

CSS stands for Cascading Style Sheets. It is used to style HTML elements and control how they appear on a webpage.

How CSS Works

CSS uses rules to tell the browser how an HTML element should look.

For example: 

h1 {
    color: blue;
    font-size: 32px;
}

Common CSS Properties

Some common CSS properties include:

  • color — changes text color
  • background-color — changes background color
  • font-size — changes text size
  • margin — controls outside spacing
  • padding — controls inside spacing
  • width — controls element width
  • height — controls element height

Why CSS is Important

Without CSS, most websites would look very plain. CSS helps developers create attractive, organized and responsive websites that work across different screen sizes.

Summary

In this lesson, you learned what CSS is, how CSS rules work, and some common CSS properties used when building websites.
