LESSON 4

JavaScript — Making Websites Interactive

JavaScript allows you to make websites interactive. It can respond to user actions, change webpage content and perform calculations.

What is JavaScript?

JavaScript is a programming language commonly used to add functionality and interactivity to websites.

JavaScript and HTML & CSS

HTML creates the structure of a webpage. CSS controls how the webpage looks, while JavaScript controls what the webpage can do. 

HTML → Structure

CSS → Style

JavaScript → Behaviour

Variables

Variables allow you to store information that can be used later in your program. 

let name = "Opeyemi";

let age = 18;

Functions

Functions are reusable blocks of code that perform a particular task. 

function greet() {
    console.log("Welcome to ABIT Tech Hub!");
}

greet();

User Interaction

JavaScript can respond to actions such as clicking buttons, typing into forms and submitting information.

Summary

In this lesson, you learned what JavaScript is, how it works together with HTML and CSS, and how variables and functions are used to create interactive websites.
