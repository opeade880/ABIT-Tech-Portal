LESSON 2

Understanding HTML

HTML is the foundation of every website. It is used to create the structure and content of a web page.

What is HTML?

HTML stands for HyperText Markup Language. It tells the browser what elements should appear on a webpage.

HTML Elements

HTML uses elements such as headings, paragraphs, images, links and buttons to build a webpage.

For example: 

<h1>Welcome to ABIT Tech Hub</h1>

<p>Learn technology and build your future.</p>

Why HTML is Important

HTML provides the basic structure of a webpage. CSS is then used to style that structure, while JavaScript can be used to make the webpage interactive.

Summary

In this lesson, you learned what HTML is, what HTML elements are, and why HTML is important when building websites.
